# Independent mission-track audit — 2026-09-01

Ten tracks, one auditor each, and then a **second agent per track whose only job was to refute
that auditor's own weakest claim**. The auditors were told that a design document describing a
pipeline is not evidence the pipeline runs, and asked to separate four states: DESIGNED (a doc
describes it), BUILT (code exists), RUNNING (there is output proving it executed), and WIRED IN
(the product calls it).

Two refutations landed, and both were against claims written by the agent being audited — which
is the point of the second pass. Five mission gates were downgraded as a result, three of them
out of PROVEN.

**The recurring failure has one shape: a code-existence claim written as an execution claim.**


## design-retrieval

The design library is real, substantial, and unusually honest about itself: 107 rules across 15 components and 21 of 23 style families, 3,101 lines of source, 60 passing tests in `packages/design` plus 10 in the worker, all running in CI. Retrieval and brief composition are built and — contrary to the package's own evidence doc, which is stale — genuinely wired into the product: `apps/worker/src/do/session.ts:659` calls `designBrief(text)` and feeds the result into the system prompt at `prompts.ts:292`, gated on a request-trait classifier. The 11 executable checks are the strongest part of the track: they run in CI against the real shipping benchmark client source and have found defects no human noticed. What is missing is the other end — there is zero recorded evidence that any real generation ever carried a brief (no occurrence of `<<<UI_GRAMMAR>>>` in any evidence file, log, or trace in the repo), no model-in-the-loop A/B, and `audit()` is called by nothing outside its own test file.

## worker-product

The worker is a genuinely deployed, multi-tenant Cloudflare product, not a prototype: 43 Hono routes, 5 Durable Objects, Supabase JWT auth with measured tenant isolation, a real alarm-driven agent loop, and a Studio plugin bridge whose every op has a Luau handler. All inference is one model — GLM-5.3 Flash on the Workers AI binding — behind a reserve/settle spend gate, and it has been exercised live (30 concurrent accounts, 12 concurrent real inferences, 0 errors). But the surface is lopsided: 26 of 43 routes are admin-only, without a paired Studio plugin the agent gets 2 of its 24 tools, and the loop's own quality gate has never been passed by an end-to-end agent run in any recorded benchmark — 19 scored rounds, 0 passes, best 5/10 on the easiest task. Around 1,400 lines of worker source (critic.ts, provenance.ts) and the entire 668-line third-party adapter set are never called by the product.
