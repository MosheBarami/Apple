# Owner-priority Roblox UI source check — 2026-09-25

The owner asked Apple to start with the Roblox-specific packs he named and keep the library in the backend. This is a source and rights check, **not an ingest record**. None of the packs below was added to Apple's backend. Free use in a customer's Roblox game does not by itself permit Apple to rehost the original pack as a SaaS asset.

One local exception to "not downloaded" was found after the initial audit: `packages/asset-library/ui-store/zerodev/UIPackPlus.rbxm` exists at **380,365 bytes**, SHA-256 `a94e11e7ebb4fef8c8602aa3bdca8cddf91532182e534434ed6a85a51e66a6b4`. Its origin is the ZeroDev download page below; it has **not** been added to the backend. The repository's static `.rbxm` scanner could not run because the required `lune` tool is not installed in Rokit. No claim is made that the file or its embedded scripts are clean. Do not commit or redistribute the binary.
