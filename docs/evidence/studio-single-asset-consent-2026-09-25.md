# Studio asset consent, 2026-09-25

The owner removed the customer-facing Creator Store versus scratch source choice. The web app already has no customer route to that selector (`apps/web/tests/internal-catalogue.test.mjs`, 2 pass). Studio 1.4.0 still displayed both choices, so this change replaces them with one explicit consent action: “May Apple add free Roblox assets to this game?” / “Allow assets and continue.” The dock explains that some assets are made by other Roblox creators, no purchase or upload is needed, builds still use Credits, and Roblox can block individual assets. A click sends only the existing `creator_store` policy. Until it is stored, the absent policy still permits no asset insertion; `from_scratch` is not authorized by this action.
