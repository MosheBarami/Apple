## Repair
Apple Studio 1.4.2 issues opaque, per-engine read references for duplicate names and their descendants. `get_instance` accepts an exact reference from the tree. References survive sibling reordering, expire after 600 seconds, are capped at 2,048 entries, and are cleared on destruction. Each read checks ancestry against an actual allowed service, including rejection of a fake Folder named Workspace. A fresh local HttpService GUID prevents aliases across plugin reloads. If GUID generation fails, ordinary tree reads continue without references.

These references are read-only. Mutation tools still require ordinary unambiguous paths. This change does not prove safe asset placement, agent insertion or commercial visual quality.
