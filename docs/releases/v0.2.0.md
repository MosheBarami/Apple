## v0.2.0 — One model, measured

_2026-08-30_

Every mode moved onto a single model, chosen by the eval suite rather than by taste — and the migration made the product both better and cheaper at once.

### Added

- Four independent spend gates, each proven against production: a per-request ceiling, a daily ceiling, a monthly billable cap and an instant kill switch — all adjustable at runtime with no redeploy.

### Changed

- One engine now runs planning, building, memory and vision — 1M context, native tool calling, multimodal. Which engine that is stays an implementation detail chosen per step.
- The gateway bills from the engine's own reported figure per call rather than from an estimate.
- Sparks recalibrated: 1 Spark = 30 neurons, so a Spark stays a meaningful unit now that the same work costs less.

### Removed

- **BREAKING** Multi-model routing is gone. It existed to move cheap steps onto a smaller model; measurement showed that routing the post-inspection step made the outcome worse — the small model read the project tree and declared the task finished instead of building it.
- Automatic retries, entirely. A retry is a second bill for the same work.

### Performance

- A full Agent build fell from $0.0139 to $0.0056 — 2.5x cheaper for the same work, on a model scoring 98.9 against 96.8 on the Roblox eval suite.
- Leaner context: tool results capped at 3,000 characters and the agent transcript at 24,000, tool definitions filtered per mode, and step budgets tightened to 3 / 8 / 14 for Plan / Agent / Super Agent.
