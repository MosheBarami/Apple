# Competitive Landscape: AI Roblox Creation (August 2026)

Research for **Golem** — AI SaaS that builds Roblox games (web app + Studio plugin) on Cloudflare Workers + Workers AI + Supabase, ~$5/mo total cost target.

Date of research: 2026-08-30. All claims verified against sources listed at the bottom; anything not directly verifiable is marked **UNVERIFIED**.

---

## 1. Roblox's Official AI (the platform incumbent)

### 1.1 Assistant in Studio (free, built in)

Roblox Assistant is a free AI agent built into Roblox Studio. As of the April 15, 2026 "Roblox Studio is Going Agentic" announcement and current Creator Hub docs, it can:

- Answer Roblox dev questions, create/modify objects and scripts in the place's data model, insert Creator Store assets, explain selected code, generate materials, generate 3D meshes and procedural models.
- **Planning Mode** (shipped April 15, 2026): analyzes code + data model, asks clarifying questions, produces an editable Markdown action plan ("structured manifest of tasks") that persists across chat sessions before executing.
- **Testing Agent (beta)**: agentic loop that reviews logs and runs automated QA playtests to verify behavior against the plan — a self-correcting build→test→fix loop.
- Cloud-persisted, multi-thread chat history per place; screenshot-analysis subagent for scene context.
- **External LLM support** (announced Feb 21, 2026; Studio integration early March 2026): bring-your-own API key for Anthropic (Claude), OpenAI, and Google Gemini, stored on-device.

**Known limits (from official docs):**
- Procedural models: **50 generations per 24-hour rolling window**.
- Model segmentation: generated models support **up to 8 parts**; imported mesh segmentation **up to 5 named parts** per iteration.
- Chats scoped to a single *place* (not the whole experience); deleted chats gone permanently.
- No published pricing/quotas for chat itself — Assistant is free with Studio, no API key required for the default models.

**Adoption stat Roblox publishes:** 44% of the top 1,000 creators used Assistant or third-party AI via MCP between 3/6/2026 and 4/7/2026.

**Gaps:** desktop-Studio-bound (no web surface for the pro tool), single-place scope, quota-limited generation, "coming soon" items still unshipped at announcement time (cross-session context storage, procedural model gen agent, parallel agents, cloud workflows, NPC simulation, node-graph visualization). Testing agent is beta and verifies against its own plan, not against a user-defined spec.

### 1.2 Studio's built-in MCP server (the door Golem walks through)

- Roblox ships an official open-source MCP server (`Roblox/studio-rust-mcp-server`) and, as of 2026, an MCP server **built into Studio**, which official docs now recommend starting with (per third-party guides; **UNVERIFIED** exact doc wording).
- Feb 21, 2026 update added agent-loop tools: `get_console_output`, `start_stop_play`, `run_script_in_play_mode` (executes scripts with automatic cleanup, returning logs/errors), `get_studio_mode`. Existing tools include object creation/property setting/script source editing and Luau execution.
- Explicitly positioned by Roblox for Claude, Cursor, and Codex integration via "unprivileged APIs." Roadmap mentions third-party MCP connections (Blender, Figma).
- Implication: Roblox is *inviting* external agents into Studio. Golem's Studio bridge rides a supported, first-party protocol rather than a fragile hack.

### 1.3 Cube 3D / CubePart / 4D generation (assets)

- **Cube 3D** (announced March 2025): Roblox's foundation model for 3D, trained on native 3D data, tokenizes shapes like an LLM tokenizes words. Open-sourced at `github.com/Roblox/cube` under a **Cube3D Research-Only RAIL-MS license** (research-only — you cannot ship it commercially in Golem). Mesh Generation API available in Studio and as an in-experience Lua API (beta).
- **1.8M+ 3D objects** generated by Cube 3D as of February 2026.
- **4D generation** (Feb 2026): adds interactivity so generated objects behave correctly in-game; 160,000+ objects in early access; Roblox reports a 64% average play-time increase in games using it.
- **CubePart** (May 2026): open-vocabulary, part-controllable 3D generation — outputs assembled sets of distinct, labeled, functional meshes.
- No public per-call pricing found for the mesh-generation API (beta) — **UNVERIFIED** whether/when it becomes metered.

### 1.4 Texture Generator (beta) and Material Generator

- Texture Generator (Studio, Window ⟩ 3D): prompt→texture on a selected MeshPart/Model, 1024×1024 output, seed control, style-image conditioning, front-view specification.
- **Limits: 5 full textures/day + 25 previews/day** during beta.
- Material Generator: prompt→tileable material variants; folded into Assistant's "generate materials" capability.

### 1.5 Code Assist

- Free AI autocomplete/suggestions in the Script Editor (pre-Assistant feature, still present). No quota published.

### 1.6 Roblox Build (July 2026) — the consumer-grade threat

- **Build**: mobile-first creation tab in the Roblox app; text prompt → playable starter game ("a cozy adventure game set in a dense forest…"). AI agents handle gameplay mechanics, environment, characters, visual style, sound.
- Public alpha **July 28, 2026**, publishing first in **New Zealand**, expanding over coming months. Available to age-checked users **9+** during alpha; published games become playable globally for age-checked users **16+** after safety review.
- **Shared back end, models, and chat history with Roblox Studio** — projects move between Build and Studio.
- Pricing: base version free; "additional paid options for power users" planned.
- Gap: produces "a basic game" starting point; competes in the same retention-based discovery as everything else. It is a casual on-ramp, not a pro idea→polished-game pipeline.

**Bottom line on Roblox first-party:** free, deeply integrated, and moving fast toward agentic — but fragmented across surfaces (Assistant in desktop Studio, Build on mobile), quota-capped on generation, place-scoped, and with verification still in beta. Roblox's own MCP strategy legitimizes external agents.

## 2. Third-Party Tools & Startups

### 2.1 Nilo (nilo.io) — best-funded-looking direct adjacent

- Browser-based 3D creative suite for Roblox: generate 3D assets from text/sketch/image, LOD/poly-count slider, one-click rigging, prompt-based animation, avatar/skin creation, real-time co-creation via share links, in-world playtesting in Nilo's own environment, one-click Roblox-optimized export to Studio.
- Open beta launched **April 2026**, free sign-up; monetizes via "Bits" credit currency (specific prices not published on landing page — **UNVERIFIED**).
- Positioning: "replace a stack of complicated tools with one fast, 3D creative suite." Runs an aggressive SEO content mill (dozens of comparison articles).
- **Gap vs Golem:** Nilo is asset/world-first, not game-logic-first. It does not claim an autonomous idea→working-game loop with code, systems, and verification; export lands assets in Studio, then you're on your own.

### 2.2 Lemonade (lemonade.gg)

- Prompt→Roblox game generation platform + Studio plugin; claims **500K+ creators** on its site; genre templates (farming, combat, survival, racing, pet sim).
- Pricing reported at ~**$20/month for 100 prompts** (credit-based; from third-party comparisons — **UNVERIFIED** exact current tiers; site hides pricing behind login).
- Gap: prompt-count economics get expensive for iteration-heavy building; no public claim of automated playtesting/verification.

### 2.3 PromptBlox (promptblox.ai)

- Web app: prompt → generated Roblox game delivered as a downloadable **.rbxlx** file to open in Studio.
- Verified pricing: Free $0 (10 credits/day, 30/mo cap, Build tier only); Lite $9.99/mo (30/day, 400/mo); Pro $14.99/mo (60/day, 800/mo, Build+Studio tiers); Pro+ $34.99/mo (150/day, 1,800/mo, all tiers incl. Architect). Generation costs: Build 30, Studio 60, Architect 100 credits. Credit packs $4.99–$49.99.
- Gap: one-shot file generation — no live Studio bridge, no iterate-in-place, no verification loop. The .rbxlx handoff is exactly the clunky step Golem's web+Studio bridge kills.

### 2.4 RBLX/ai (rblxai.com)

- Not a game builder: AI **icons/thumbnails/vector graphics** for Roblox creators + a code assistant. Hobby free (40 code-assistant messages/day); Pro $15.99/mo (90 credits/mo); Unlimited $23.99/mo (180 credits/mo); also sells credits for Robux (10 credits = 999 Robux). Adjacent, not competing on the core loop.

### 2.5 Creator Store / DevForum AI plugins (long tail)

- **Ropanion** (free plugin): agentic in-Studio assistant; BYO key for OpenRouter/OpenAI/Anthropic/Gemini/Bedrock; multi-file edits, object generation, workspace context. Weakness (self-acknowledged): users wait on plugin updates for new providers vs MCP's provider-agnosticism.
- **RoAssistant, Lux, RobloxAIBuilder** (free/freemium DevForum plugins): in-Studio chat/agents of varying quality.
- Reported in 2026 roundups (single-source, treat as directional/**UNVERIFIED**): **RoCode v2.0** ("native-feel" Studio UI), **Vibe Coder Pro** (on-platform multi-file edits), **Picoo** (claims most-installed third-party AI plugin; 10,000 Creator Store votes at 88% positive, listed since Aug 2025).
- Pattern: all are Studio-embedded chat/edit tools competing on UI polish and pricing; none owns a full idea→game→verified loop or a web surface.

### 2.6 Pro devs using general AI coding tools

- A real and growing workflow: **Cursor / Claude Code / Codex + Rojo (file sync) or the official Studio MCP server**. Roblox itself markets this path (the 44% stat counts "third-party AI via MCP"). Community guides (Feb–Aug 2026) document Claude directly creating objects, editing scripts, running Luau, and driving playtest cycles through MCP.
- Gap: this stack is powerful but DIY — requires terminal comfort, MCP setup, prompt discipline, and a paid Cursor/Claude subscription. Nobody has productized it for the median Roblox creator (largely teens/hobbyists). That productization gap is Golem's lane.

### 2.7 Adjacent asset generators

- **Meshy AI**: text/image→3D leader; Free 100 credits/mo (CC BY 4.0 outputs), Pro $20/mo (1,000 credits), Premium $40/mo (3,000), Ultra $100/mo (8,000), Studio $70/mo team plan. Rigging/animation currently 0 credits. Used by Roblox devs but not Roblox-native (topology/scale cleanup often needed).
- **Taqla, PLAYTEX** etc.: niche texture generators marketed at Roblox devs.

### 2.8 General vibe-coding platforms (adjacent, not Roblox-native)

- **Rosebud AI**: prompt→browser game (web tech, not Luau/Roblox). Free tier with monthly AI credits; **Pro Creator $19.99/mo** unlocks selling games, private projects, higher limits. Does **not** export Roblox games — assets need manual rework for Studio.
- Bolt/Lovable/v0-class tools: no Roblox target. They matter only as UX benchmarks — users now expect "describe it, watch it build, see it run" with live preview and one-click deploy.

## 3. Trademark / Brand Constraints on "Roblox" in Marketing

From Roblox's Name & Logo Community Usage Guidelines and the 2022 brand-guidelines update (help-center page returns 403 to bots; rules verified via DevForum announcement + search excerpts):

- **Logo:** general use of the Roblox logo/"Tilt" icon in third-party creative is **not permitted**. The **"Now on Roblox" badge** exists for promoting *experiences* digitally without approval; offline use (billboards, TV, print) needs written approval. The badge is for experiences, not tools — **UNVERIFIED** whether a SaaS tool qualifies to use it at all; assume no.
- **Name in product names:** Creator Third Party App Terms: third-party apps may not use Roblox's name/marks/logo without prior written consent. The published safe pattern (from the books precedent): Roblox name may appear **not as the first word**, clearly **UNOFFICIAL**, descriptive use only. On-platform, "Roblox"/"Blox" is banned in experience titles created after June 22, 2022.
- **Practical guidance for Golem:** brand as **"Golem — AI game builder for Roblox"** (nominative, descriptive "for Roblox," never "RobloxGolem" or "GolemBlox"-style, never first word, no Roblox logo/Tilt/font/red branding, no implication of endorsement); add a footer disclaimer: "Golem is not affiliated with, endorsed by, or sponsored by Roblox Corporation. Roblox is a trademark of Roblox Corporation." Don't register domains containing "roblox." Competitors (rblxai.com, promptblox.ai) skate closer to the line — that's their risk, not a precedent.

## 4. Positioning: The 3 Sharpest Angles for Golem

1. **The full idea→working-game loop, verified.** Every competitor stops early: Roblox Build makes "a basic game" starter; PromptBlox emails you an .rbxlx; Nilo hands you assets; Studio plugins edit code you must test yourself. Roblox's own Testing Agent is beta and Studio-locked. Golem's claim: *it doesn't stop until the game actually runs* — plan → build → playtest via the Studio MCP loop (`run_script_in_play_mode`, `get_console_output`) → fix → repeat, with the pass/fail receipts shown to the user. "Verified working" is a category nobody owns yet.

2. **The web+Studio bridge.** Roblox split its own story: casual creation on mobile (Build), pro tooling on desktop (Assistant). Nobody serves the middle: start from any browser (Chromebook kids, phones, school machines that can't run Studio), and when you open Studio, Golem is already there continuing the same project over MCP — no file downloads, no copy-paste, no "export." One project, two surfaces, zero handoff friction. This also mirrors Roblox's shared-backend Build↔Studio vision — but cross-vendor and available now.

3. **Autonomy at hobbyist prices.** The real autonomous stack today is Cursor/Claude Code + MCP: powerful, but $20+/mo, terminal-shaped, and adult-shaped. Roblox Assistant is free but quota-boxed (50 procedural models/day, 5 textures/day) and reactive. Golem productizes the agentic loop — plans, executes multi-step, self-tests — at an impulse price point the Roblox demographic (and their parents) will pay, undercutting Lemonade's ~$20/100 prompts and PromptBlox's $14.99 mid-tier. The $5/mo infra cost target makes a $9–12 price with real margin plausible.

### Landing-page "wow"

The demo that differentiates: **a live split-screen where a one-sentence idea becomes a running game while you watch** — left pane: Golem's agent narrating its plan and checking off steps; right pane: the actual Roblox viewport where the map appears, NPCs spawn, and then *Golem playtests it itself* (character runs the obby, console shows tests passing) — ending on a "Play it now" join link. The wow is not generation (everyone shows generation); it is the agent **playing and passing its own game**. Secondary wow: type on your phone → watch it materialize inside Studio on your desktop in real time. Copy angle: "Describe it. Golem builds it, tests it, and proves it works."
