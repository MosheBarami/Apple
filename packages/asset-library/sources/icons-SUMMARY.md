# Icons / 2D UI sources: summary

Catalog: `icons.jsonl` (543 entries, one JSON object per line, deduped by normalized URL).
Use split: **245 import-ok / 298 reference-only**.

The licence rule was strict. import-ok means CC0/PD, OFL/Apache fonts, free Creator Store decals or UI models, or an
explicit commercial-reuse licence (CC BY, MIT, ISC, or a creator's written "free for commercial use"). Anything
paid, unclear, share-alike, ripped IP (PSX/Fortnite/CoreGui), portfolios, Pinterest and ArtStation/Behance/Dribbble
is reference-only. Rows that need attribution (CC BY 3.0 game-icons.net, CC BY 4.0 Twemoji) say so in `license`.
Rows marked "verify" (CraftPix freebies, Figma Community files) should get a licence re-check before shipping.

## Most productive queries

1. `game-icons.net tags index` and tag pages (money/egg/crown/gift/bottle/rank): 40+ CC BY rows, all import-ok.
2. `free cartoon font OFL bubbly game title Google Fonts`: 32 font rows, all import-ok.
3. `site:create.roblox.com <item> icon decal` variants (VIP, cash, rebirth, trade, backpack, daily reward, spin wheel): the biggest import-ok source (75 rows).
4. `devforum roblox free icon pack simulator ui`: led to most of the verified free Roblox-native packs.
5. `opengameart CC0 <coin|gem|potion|GUI> icons`: 35 CC0 rows.
6. `itch.io free cartoon game ui icons pack commercial use`: the best simulator-style packs (gvesster, Zxgly, K7_42, Asep Bagus, filwarka).
7. `kenney ... CC0` (game icons, UI pack, emotes, generic items): small row count but the highest quality.
8. `figma community roblox ui kit free`: 14 kits (CC BY 4.0 per Figma terms, verify).
9. `roblox ui designer portfolio carrd` / `artstation|behance roblox simulator ui`: reference-only style leads.
10. Google Images leads (Pinterest boards and ideas pages): only reference value. Most pins do not resolve to an original creator.

Diminishing returns: the final round returned 11 duplicates out of 15 hits.
Blocked: SVG Repo (HTTP 429) and itch tag indexes (403), so SVG Repo rows stay reference-only until each collection
licence is checked.
