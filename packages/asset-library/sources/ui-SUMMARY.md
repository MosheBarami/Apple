# UI sources: summary

Catalog: `packages/asset-library/sources/ui.jsonl` has 1546 entries, one JSON object per line.
It is deduped by normalized URL, then again by asset, file, topic, video or repo ID.
Nothing was downloaded, no accounts or logins were used, and no forms were submitted.

## Licensing rule applied

An entry is `import-ok` only when one of these holds:

- the page states CC0 or public domain,
- it is a free Roblox Creator Store asset,
- it has an explicit license allowing commercial reuse, such as MIT, Apache, OFL, or CC-BY with attribution noted.

Everything else is `reference-only`. That covers:

- DevForum threads
- GitHub repos with no license, a custom license, or copyleft
- Figma files whose license line was not verified
- paid or personal-use itch packs
- Gumroad and BuiltByBit listings
- YouTube and Reddit

Entries that recreate a named third-party game's UI (Pet Simulator X, Doors, Brookhaven, etc.) carry an "IP caution" note in `style`, even when they are technically import-ok.

## Most productive queries and sources

1. **DevForum search JSON** (`devforum.roblox.com/search.json?q=<q> category:74`, Community Resources) gave about 560 threads.
   - Best queries: "ui kit", "free ui", "simulator ui", "shop ui", "ui pack", "icons", "gui", "hud", "open source ui", "ui library".
   - Links inside threads were harvested too (creator-store, itch, GitHub and YouTube URLs).
2. **Roblox toolbox API** (`apis.roblox.com/toolbox-service/v2/assets:search`, Model / Decal / Plugin) gave about 490 entries.
   - Best queries: "shop gui", "simulator gui", "gamepass shop", "settings gui", "currency gui", "coin gui", "inventory gui", "loading screen", "code gui", "simulator ui".
   - It became saturated after round 3 (45 of 46 results were duplicates).
3. **itch.io listing pages** fetched through Firecrawl scrape. curl gets a 403 on listings, while item pages work with curl.
   - `itch.io/game-assets/free/tag-gui` with CC0 license filter gave all import-ok results.
   - `game-assets/free/tag-cartoon/tag-gui` gave the cartoony packs.
   - `game-assets/free/tag-roblox` gave the Filwarka, Zxgly, gvesster and RBLX Essentials packs.
4. **GitHub repo search** (`gh api search/repositories`).
   - Best queries: "roblox ui", "roblox gui library", "roblox fusion components", "roact components", "roblox topbar", "roblox icons".
   - Licenses were read from repo metadata.
5. **Kenney** `kenney.nl/assets/tag:interface` gave 26 entries, all CC0.
6. **OpenGameArt** searches for "cartoon gui", "button", "ui pack" and "cc0 ui". The per-item license field was checked.
7. **Firecrawl search** with `site:figma.com/community roblox ui`, `site:reddit.com r/robloxgamedev free ui`, `site:gumroad.com roblox ui free` and `site:builtbybit.com roblox ui`.
   - Most results were reference-only.

Blocked or low-yield sources:

- Reddit JSON is blocked, so Firecrawl search was used instead.
- BuiltByBit listings give 403.
- Figma pages need JavaScript, so license lines were rarely verifiable.
- Gumroad "free" listings are usually pay-what-you-want with a personal license.
