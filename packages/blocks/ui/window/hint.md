The window a menu screen lives in (StudKit): a slate frame, a studded header in `token` with the title and a big
icon overflowing it, and a berry X on the edge, in the centre of the screen. Choose it first for any shop, inventory, upgrades,
rewards, settings, codes, quests or leaderboard screen; the content blocks go inside it on the same screen. One window per
screen; title one or two words. startOpen false waits for a HUD tile with action open:<screen>.
