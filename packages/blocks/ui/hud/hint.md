The always-on HUD at the top of the screen: up to 4 currency counters (icon emoji, starting value, colour), up to 3
buttons beside them (label, icon, colour, action) and up to 2 progress bars underneath (label like "Level 3",
progress 0-1, colour). Set a counter's stat to a currency name (with the currency block) and it follows the player's
balance live (or any player attribute, e.g. Round from round-loop). A button's action opens a panel or asks the server.
