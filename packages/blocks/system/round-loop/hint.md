Lobby -> round -> lobby, on the server. With minPlayers in the game, the lobby counts down, everyone is moved to the
spawn parts in Workspace.<arena> (parts whose names start with Spawn; build them with a zone or prop block), and when
the round ends the players still alive and in it get the reward and return to the lobby spawn. Every player has the
attribute Round (e.g. "Lobby 0:23", "Round 1:45") for a hud counter (stat Round), and ReplicatedStorage has Phase and
TimeLeft. Needs currency.
