# Accessibility

- **Target:** WCAG 2.2 AA for studpilot.app, the website and the app.
- **Supported browsers:** the latest Chrome, Edge, Firefox and Safari on desktop.
- **Every flow** (sign-in, pairing Studio, building, credits, settings, deleting the account) works with the keyboard
  alone and with a screen reader.
- **Known limits:** the Roblox Studio plugin runs inside Studio and follows Studio's own accessibility.
- **Report a barrier** to support@studpilot.app or with the Bug issue template. We reply within 7 days.
