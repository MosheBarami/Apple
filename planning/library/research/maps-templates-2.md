# Library categories 3 and 17: complete maps and game templates from open sources (deep research, 2026-10-08)

Question: which Roblox templates, starter places and complete maps carry a licence that allows reuse inside other people's games (MIT, Apache-2.0, BSD, CC0, CC-BY), and can they reach the targets (50 templates, 300 maps)? Deep-research workflow: 5 angles, 17 sources fetched, 79 claims extracted, 25 verified by three adversarial votes each (19 confirmed, 6 killed).

## Answer

The 50-template and 300-map target is not reachable from the open, permissively licensed sources verified here. Roblox's own material is the main obstacle: the 23 official Studio templates carry no stated reuse licence, the Limited Use License is non-sublicensable and not a permissive licence, and the MIT-licensed Roblox/resources repo holds only about 12 experiences (just Baseplate and Obby among the Studio templates). The other verified MIT sources are tiny: Roblox/Old-Open-Source-Levels (about 28-31 pre-2024 community levels, murky authorship), dwmk/RobloxGames (5 places, all first committed in 2024) and rojo-rbx/desert-bus-2077 (1 demo). The one CC0 itch.io pack checked is raw 3D meshes, not a place. The verified total is roughly 45-50 usable places at best, below the 50-template target and nowhere near 300 maps, and asset-ID ownership remains a problem for most of them.

## Findings (confidence, then claim, evidence and sources)

### Roblox's 23 official Studio templates (Platformer, Laser Tag, FPS System, Racing, Classic Obby, Capture the Flag, Team/FFA Arena, Combat, Concert, Move It Simulator, Mansion of Wonder, Classic Racing, Baseplate, etc.) are described only as uncopylocked games. The docs pages that list them state no licence, reuse or redistribution terms, so they cannot be cited as permission to reuse them in other people's games.
- **Confidence:** high; votes: 3-0 on each of the two source claims
- **Evidence:** The creator-docs templates file has exactly 23 headings and the intro says 'Templates are uncopylocked games that provide a set of default objects.' Neither it nor the educator guide on designing templates mentions licence or reuse terms. Uncopylocked only means a user can copy the place; it is not a redistribution licence. Reuse rights would have to come from the Roblox Terms of Use, which none of the verified claims cover.
- **Sources:** https://github.com/Roblox/creator-docs/blob/main/content/en-us/resources/templates.md, https://create.roblox.com/docs/en-us/education/support/designing-studio-templates

### Roblox's Limited Use License (which Roblox's own sample content such as Battle Royale is published under) is not a permissive open-source licence. It grants a limited, non-exclusive, non-transferable, non-sublicensable, revocable permission. Use is for incorporating the software into your own larger applications on Roblox. Copies may go only to collaborating developers who agree to the same licence. A library that auto-inserts covered content into arbitrary users' games is therefore not clearly covered, and it fails the MIT/Apache/BSD/CC0/CC-BY filter.
- **Confidence:** high; votes: 3-0 (licence nature, sublicensing); 0-3 against the 'reuse in other creators' games is allowed' reading
- **Evidence:** Primary licence text: 'limited, nonexclusive, non-transferable, non-sublicensable, revocable permission' and 'Sublicensing is not permitted.' Roblox can terminate at any time, and the licence bars use with competing services. The Battle Royale docs page (create.roblox.com/docs/resources/battle-royale) says that sample is under this licence and links to a public place, not a GitHub repo. One claim that tried to characterise the permitted scope as reuse inside other creators' Roblox games was refuted 0-3 as unsupported by the text. The licence's silence on other games is itself a risk, not a grant.
- **Sources:** https://create.roblox.com/docs/resources/limited-use-license

### Roblox/resources is the one official Roblox repo that is both MIT-licensed (Copyright 2021 Roblox Corporation) and contains place files. It holds only 12 experience folders: dialog-system, fluid-force-sensor, glider, gold-rush, ias-direction2d-example, laser-tag-1A-tutorial, npc-state-machine, plant, procedural-models, templates, top-down-camera, weather-island. Among Studio templates it has only baseplate and obby. It adds roughly 5-8 genre-like places at most, many being feature demos. About 1,086 rbxassetid:// references (17 files) point to assets that may not transfer, and the repo is a 2026 creation (not pre-2024 as a repo, though some files may be older).
- **Confidence:** high; votes: 3-0 on each of the three claims
- **Evidence:** LICENSE.md is the standard MIT text; the GitHub API reports spdx_id MIT and last push 2026-10-06. The contents API shows exactly 12 folders under experiences/ and 2 under experiences/templates (baseplate, obby). A recursive search for 'racing' found nothing. Bundled dependencies carry their own copyright notices (e.g. Freeze, Copyright 2022 Benjamin Brimeyer). MIT cannot grant rights over Roblox-hosted assets owned by others.
- **Sources:** https://github.com/Roblox/resources

### Roblox/Old-Open-Source-Levels is the largest verified permissive map source but is small: about 28 published levels plus 3 marked Unfinished (about 28-31 .rbxl files in four folders), MIT-licensed (Copyright 2020 Roblox Corporation), archived read-only since 11 June 2020. The README says 'One may legitimately use material from any of these games in any project.' Entries date from April 2007 to October 2013, so they are human-made and pre-2024. The rights chain is unclear because many entries are credited to community authors while the copyright line names Roblox, and these old places likely carry legacy asset references.
- **Confidence:** medium; votes: 3-0 (repo status/licence); 2-1 (README grant); 2-1 (count/date)
- **Evidence:** Verified via the GitHub API: owner Roblox, archived true, last push 2020-06-11, licence MIT. catalog.md has 28 dated entries and 3 Unfinished rows (the default branch is master). The claim's '2007-2011' range was corrected to 2007-2013. The README and MIT grant are broad, but the votes on the README and count claims were split 2-1 because of the authorship ambiguity.
- **Sources:** https://github.com/Roblox/Old-Open-Source-Levels

### Roblox's GitHub organisation (110 public repositories) does not host its official sample games such as Battle Royale, Laser Tag or Mystery Dungeon as standalone repos. Those samples live as Studio/Creator Hub places or inside Roblox/resources, under the Limited Use License or MIT depending on the item. The only map-like repo on the org is Old-Open-Source-Levels.
- **Confidence:** medium; votes: 2-1 (surviving claim); 0-3 and 1-2 (broader versions refuted)
- **Evidence:** All four listing pages were checked (30/30/30/20), and direct probes of github.com/Roblox/battle-royale, /laser-tag and /mystery-dungeon returned 404. The broader claim that 'none of the 110 repos is a sample, template or starter place' was refuted 0-3, because place-ci-cd-demo, Old-Open-Source-Levels and rbx-test-files are partially relevant, and the narrower 'one level collection' framing was refuted 1-2 on wording. Only the narrower claim (no standalone official sample-game repos) survived.
- **Sources:** https://github.com/orgs/Roblox/repositories, https://create.roblox.com/docs/resources/battle-royale

### Community and tooling-org sources yield almost nothing. rojo-rbx has 14 public repos and only one game project, desert-bus-2077 (MIT, a self-described rough demo with Tarmac-managed assets, last push 24 Jan 2024), and its other repos are tooling or test fixtures (rbx-test-files has 5 format-test baseplates). dwmk/RobloxGames (MIT, Copyright 2024 Dewan Mukto) has 5 .rbxl files (BanglaBattlegrounds, BrokenPVPgame, DemonHunting, Photon_2, SaveHer), several abstract or unfinished. The whole repo was first committed in August 2024, so it fails the pre-2024 filter even though filenames carry July 2024 stamps.
- **Confidence:** high; votes: 3-0 on desert-bus-2077 and RobloxGames claims; 0-3 on the 'none are templates' phrasing
- **Evidence:** GitHub API: rojo-rbx public_repos=14, desert-bus-2077 MIT, pushed 2024-01-24. dwmk/RobloxGames: created 2024-08-06, 5 .rbxl files confirmed in the recursive tree, MIT LICENSE text confirmed. The claim that none of the other rojo-rbx repos is a template was marked refuted only because rbx-test-files contains place fixtures; they are still not usable templates. The rojo repo itself is MPL-2.0 and not on the permitted list.
- **Sources:** https://github.com/orgs/rojo-rbx/repositories, https://github.com/dwmk/RobloxGames

### The one itch.io source examined, hocineache's Modular Dungeon Assets, is CC0 but is 3D mesh building blocks (.fbx/.obj in a single 17 MB zip), not a Roblox place or map, so it contributes 0 templates and 0 complete maps. Its release date is not shown on the page. It would need to be assembled and imported as meshes, which makes it a possible asset input rather than a map.
- **Confidence:** medium; votes: 2-1 (CC0 clears the bar); 3-0 (contents are meshes, not a template)
- **Evidence:** The page says 'This asset pack is released under the CC0 license' and 'No generative AI was used.' It shows no Roblox mention and no date. The CC0 claim is the creator's own on the listing, with no LICENSE file confirmed inside the zip.
- **Sources:** https://hocineache.itch.io/modular-dungeon-assets

### Asset-ID portability is a systemic problem. Roblox assets are either Restricted (owner permission needed) or Open Use (any creator or game may use them). Asset Privacy applies by default only to Images, Decals and Meshes, and only to newly created assets. So places that reference rbxassetid:// IDs created by others or by Roblox may break or be unusable in other people's games, and an MIT licence on the place file does not cure that.
- **Confidence:** high; votes: 3-0
- **Evidence:** The docs say 'Restricted assets need the owner's permission before another creator or game can use them. Open Use assets can be used by any creator or game.' The Roblox/resources repo has 1,086 rbxassetid:// references. Audio, models, animations and packages follow their own defaults, so per-asset checks are needed.
- **Sources:** https://create.roblox.com/docs/projects/assets/privacy, https://github.com/Roblox/resources

### Quantified reachability: the verified open-licence pool adds up to about 45-50 places in total, split roughly 28-31 old community levels (Old-Open-Source-Levels), 5 (dwmk/RobloxGames, fails the date filter), 1 (desert-bus-2077), and about 12 reference experiences of which only a handful are playable genre starters (Roblox/resources). Of these, the date-eligible and clearly licensed ones fall well under 50, and the 300-map target is out of reach, by a factor of roughly 6 or more. The only route to scale is a different source type (e.g. many individual authors' repos, or custom-built blocks) rather than these curated sources.
- **Confidence:** medium; votes: Derived from verified 3-0 and 2-1 claims
- **Evidence:** This is a sum of the verified per-source counts, not a separately verified figure. The pre-2024 filter removes dwmk/RobloxGames (5) and arguably Roblox/resources as a 2026-created repo; asset-ID dependence and the unclear authorship of old community levels cut the usable number further. A broad GitHub or itch.io sweep was not in the verified set, so unknown long-tail sources may add some.
- **Sources:** https://github.com/Roblox/resources, https://github.com/Roblox/Old-Open-Source-Levels, https://github.com/dwmk/RobloxGames, https://github.com/orgs/rojo-rbx/repositories

## Caveats

The verified evidence covers only a handful of sources; no broad GitHub code search, OpenGameArt or additional itch.io sweep survived verification, so the long tail of small community repos is unmeasured. The 45-50 total is my sum of per-source counts and is an upper bound, not a verified figure. Nothing verified addresses the Roblox Terms of Use or Creator Terms on reusing Studio templates; only the absence of licence text on the docs pages is confirmed. Old-Open-Source-Levels has real authorship ambiguity, since MIT is granted by Roblox over community-made 2007-2013 levels. Per-place asset-ID dependence was measured only for Roblox/resources, and only as a grep count, not by actually opening the places. Several repo-level findings come from live GitHub API state on 2026-10-08, which will change. The Roblox/resources repo is dated 2026 as a repository, which does not satisfy a strict 'before 2024' filter even though some files may be older. Five claims about open-game-eval and some scope-broadening claims were refuted, so those were not used as evidence.

## Open questions

- What do the Roblox Terms of Use and Creator Terms actually say about reusing the built-in Studio templates (Racing, Obby, etc.) and sample places in other creators' games? Does the Limited Use License cover the Studio templates at all?
- How many of the places in Roblox/resources (plant, laser-tag, gold-rush, glider, weather-island) are full playable genre starters, and what fraction of their assets are Roblox-owned or Open Use versus third-party and restricted?
- Do individual GitHub repos with Rojo projects or .rbxl files under MIT/Apache/CC0 (beyond the orgs checked), plus OpenGameArt and other itch.io listings, add enough pre-2024 human-made places to change the count materially?
- Can the Old-Open-Source-Levels community levels be relied on given that the MIT grant comes from Roblox while the original authors are credited, and do those places depend on retired or non-transferable asset IDs?

## Refuted claims

- (1-2) Roblox/open-game-eval is an MIT-licensed evaluation framework for testing LLMs on Roblox game development tasks, not a collection of game templates or maps. (https://github.com/Roblox/open-game-eval)
- (0-3) The repository has a Places folder and its eval scripts reference place files such as racing.rbxl, but the README says these are limited to Roblox's own templates. So it adds no new community templates or maps, and the contents of the Places folder were not listed on the page. (https://github.com/Roblox/open-game-eval)
- (0-3) Permitted use is incorporating the Licensed Software into your larger applications for deployment on Roblox, and use is barred in connection with alternative or competitive services. Reuse inside other creators' Roblox games is allowed, but not elsewhere. (https://create.roblox.com/docs/resources/limited-use-license)
- (0-3) None of the org's other repositories is a game template, starter place or map pack. They are tooling, such as rojo, rbx-dom, rokit, tarmac, remodel, run-in-roblox and rbxlx-to-rojo, plus website and brand repositories. The page labels none of them as templates. (https://github.com/orgs/rojo-rbx/repositories)
- (0-3) The Roblox GitHub organisation lists 110 public repositories across 4 pages (30/30/30/20), and none of them is described as a sample game, template or starter place. They are mostly Luau libraries, tooling, ML projects and infrastructure (Chef cookbooks, Nomad, Cilium). This means the org cannot supply the 50 templates the research question targets. (https://github.com/orgs/Roblox/repositories)
- (1-2) The one level collection in the org is Roblox/Old-Open-Source-Levels, listed with an MIT licence. It is an old repo of levels that can be freely modified, not a set of complete playable templates. It is probably the best permissive map source on the org page. Its date (likely well before 2024), level count and asset-ID dependencies are unverified and need a direct check. (https://github.com/orgs/Roblox/repositories)
