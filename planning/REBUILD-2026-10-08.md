# StudPilot rebuild, 2026-10-08 (owner direction of 2026-10-08)

This replaces the kit/blocks approach. The owner's message of 2026-10-08 is the direction; where it reverses an
earlier decision (projects are back; no pairing code; no edit-consent gate; no prompt library; no premade creative
content) it wins.

## Decisions (each grounded in a real implementation)

| Area | Decision | Grounded in |
|---|---|---|
| Agent loop | ONE agent: `AIChatAgent` (`@cloudflare/ai-chat` 0.12.1, `agents` 0.27.0) per project, AI SDK 7 `streamText` + `stopWhen`, `workers-ai-provider` 4. No planner/builder/reviewer/tester, no sub-agents. | Anthropic "Building effective agents" (simple loop first); Cloudflare chat-agents docs (SQLite persistence, resumable streams, durable recovery) |
| Context | Small system prompt (identity, project facts, how to work) + skill index; skills are loaded on demand with `load_skill`. Older tool output pruned with `pruneMessages`. | Anthropic "Effective context engineering"; agentskills.io spec (3-level progressive disclosure) |
| Skills | `packages/skills/<name>/SKILL.md` (+ `references/*.md`): knowledge and method, never preset designs or assets. | agentskills.io |
| Tools | Modelled on Roblox's own Studio MCP tool set (read tree/script, grep, edit script, create/set/delete instances, execute Luau, search/insert asset, play test, console output, docs, skill). <= 25 tools. | create.roblox.com/docs/studio/mcp; Roblox/studio-rust-mcp-server |
| UI engine | `build_ui`: the model writes a declarative tree (its own colours, fonts, sizes, layout); the compiler emits correct Roblox layout objects; the plugin measures the real result (TextFits, overlaps, overflow, off-screen) at several viewport sizes and returns defects the model must fix. | Docs search | Real search over the full Roblox Creator Docs (Roblox/creator-docs, CC-BY-4.0) and Luau docs (luau-lang/site, MIT), D1 FTS5 index, every hit carries its live URL; `read_doc` fetches the live page. | Chat UI | AI Elements + Streamdown + use-stick-to-bottom fed by `useAgentChat` (real token streaming of text, reasoning, tool calls). | elements.ai-sdk.dev; vercel/streamdown |

## Wire contract (agent <-> web)

- Agent class `StudPilotAgent` in `apps/studio`, one instance per project id.
- WebSocket/HTTP path: `/studio/agent/<projectId>` (through the main worker's `/studio/*` proxy). Auth: `?token=<supabase access token>`.
- Client: `useAgent({ agent: 'studpilot-agent', name: projectId, basePath: 'studio/agent/' + projectId, query: async () => ({ token }) })` then `useAgentChat({ agent })`.
- Message parts the UI must render: `text`, `reasoning`, `tool-<name>` (input-streaming / input-available / output-available / output-error), `source-url` (citations), `data-credits` ({ remaining }) and `data-progress` ({ label }).
